POUR CHACUNE DES 30 BANDES D'UNE IMAGE (AU PLUS 30 IMAGES PAR SECONDE)

1Figer

début d'image : view = game ; la physique continue sur game

2Composer

oa_render_band() dessine 8 lignes : décor, objets, texte

3Comparer

empreinte de chacun des 10 blocs de 32 × 8 avec celle déjà à l'écran

4Copier

les blocs modifiés contigus dans transmit[] ; rien si tout est identique

5Envoyer

fenêtre CASET, PASET, RAMWR puis DMA SPI1 ; la boucle repart aussitôt

6Valider

fin du DMA (interruption) : écran libéré, empreintes enregistrées
