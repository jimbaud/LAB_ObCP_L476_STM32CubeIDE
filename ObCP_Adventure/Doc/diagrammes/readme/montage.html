À VÉRIFIER AVANT DE BRANCHER LE SHIELD

  • sur l'ObCP, A4 = PC1 et A5 = PC0 ne sont pas l'I2C : ponts A4/A5 du shield ouverts
  • l'ObCP n'a pas le connecteur ICSP : le shield doit prendre le SPI sur D11 à D13
  • IOREF vaut 3,3 V ; contrôler les ponts VddIO et les tirages I2C du shield
  • D2 (PA10) est reliée à USB_ID : le jeu n'utilise pas l'interruption du tactile
